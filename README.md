# AI Search Algorithms

## Practical Title

Performance Evaluation of Various Search Algorithms for Problem Solving

## Problem Statement

Evaluate the performance of various algorithms (Uninformed, Informed, Local Search and Constraint Satisfaction) of problem solving through Search.

## Algorithms Implemented

### Uninformed Search
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Uniform Cost Search (UCS)
- Depth Limited Search (DLS)
- Iterative Deepening Search (IDS)
- Bidirectional Search

### Informed Search
- Greedy Best First Search
- A* Search

### Local Search
- Hill Climbing

### Constraint Satisfaction
- N-Queens using Backtracking

## Technologies

- Python
- heapq
- collections
- math
- time

## How to Run

Run the following command:

python ai_search.py

## Performance Measures

The program measures:

- Execution time
- Nodes explored
- Path length
- Path cost
- Number of iterations
- Backtracking count
